§C ANN

Brute-force vs HNSW

小语料精确扫全库；大语料用近似图索引换速度。

brute-force query → 计算全库 cosine → 精确 top-k
→
HNSW ANN query → 图上贪心搜索 → 近似 top-k

本项目 dense 面板仍用 brute-force，作为后续 ANN 近似召回的 ground truth。

ef / M 交互示意

教学模拟，非真实 benchmark。

召回损失 = 嵌入表达力问题（买不回） × ANN 近似问题（通常可用更高 ef 买回）。

§D 评估

recall@k = 命中的相关文档数 / 全部相关文档数
precision@k = 命中的相关文档数 / k
MRR = 1 / 第一个相关结果的排名

当前 query 实时指标（@5）

只有当前输入能在 `data/queries.json` 中找到 ground truth 时才计算。

§E 横向对比

基于 `data/queries.json` 全部 query 与 `relevant_ids` 自动计算。BM25 / 图式渐近同步出结果；Dense 需要模型就绪后运行。

Dense 未加载时，按钮会先加载模型再运行对比。

总览指标

macro recall@5 / precision@5 / MRR / nDCG@5

逐 query 明细与漏召回归因

每行高亮 recall@5 最高方法；漏召回按 `trap` 字段解释。

工程结论：没有单一方法全胜，生产应融合 dense 粗召回 + 图式沿链补召回 + rerank。
