Agent 架构 · 第 1 课

什么是 Agent(vs 普通 LLM)· Agent Loop 控制循环 · 自治度分级 · 设计模式总览　|　知识地图

😌 当你零基础。 这一课只追一件事:"Agent" 到底比"你平时用的 ChatGPT 那种一问一答"多了什么? 答案是一个循环——想 → 做 → 看 → 再想。看懂这个循环,后面规划、工具、记忆、多智能体全是往这个循环里加零件。以能点的图为主。

①

普通 LLM 一问一答 vs Agent

基础

你平时用的大模型(ChatGPT 那种)本质是一次性的问答:你问一句,它答一句,不能真去做事(不能查实时资料、不能调工具、不能执行动作)。Agent 是在它外面套了一个循环 + 手脚,让它能自己想办法、动手、纠错,直到把目标完成。

🗣 普通 LLM 调用

问题 ──▶ [ LLM ] ──▶ 答案
  • 一次性:一问一答,结束
  • 没有手脚:只能靠"脑子里已有的知识"回答
  • 问它"东京现在下雨吗" → 它不知道(没联网、没工具)
  • 像个博学但被关在小黑屋、只能动嘴的人

🤖 Agent

目标 ──▶ [ 想→做→看→再想… ] ──▶ 结果
  • 循环:反复"思考→行动→观察",直到搞定
  • 有手脚:能调用工具(查天气、搜网、算数、写文件…)
  • 问它"东京现在下雨吗" → 它自己去调天气工具再回答
  • 像个能查资料、能动手、会自己想办法的人
Agent = LLM(大脑) + 工具(手脚) + 循环(自主) + 记忆
📌 一句话:LLM 是"会思考的大脑",但光有大脑只能空想。Agent = 给这个大脑接上"手脚(工具)"和"一个不断'想-做-看'的循环",让它能真正去完成任务,而不只是回答问题。
②

核心:Agent Loop(想 → 做 → 看 → 再想)

核心

这是整个 Agent 的心脏。给一个目标后,Agent 不停地转这个圈:① 思考(想下一步干嘛)→ ② 行动(调一个工具)→ ③ 观察(看工具返回啥)→ 回到 ①,直到它觉得"信息够了",才给最终答案。点「下一步 ▶」,跟着一个真实例子转一圈:

🔍 诚实说明:上面"思考"里那些内心独白,是模拟一个大模型在这一步大概会输出的推理(真实系统里这句话是 LLM 现场生成的)。这种"边想边做、把推理和行动交替进行"的模式,业界有个正式名字叫 ReAct(Reason + Act)——下一课(规划与推理)会专门展开。
📌 记住这个圈:Agent 的一切都围绕 思考→行动→观察 的循环。"行动"就是调用工具(第③课),"观察"是把工具结果喂回给大脑,让它决定下一步。什么时候停?由大脑自己判断"够了"。后面所有高级能力(规划、反思、记忆、多智能体),本质都是给这个循环加零件。
③

自治度分级:Agent 能有多"自主"

核心

"Agent"不是非黑即白,而是一条自主程度的光谱——从"只给建议、人来做"到"完全自己干"。点下面每一档看它什么意思(右边红条 = 自主程度/威力,也代表风险):

📌 最重要的权衡(面试高频):自治度越高 → 越强大,但也越危险(它自己做的决定/动作,错了或被攻击的代价越大)。所以自治度越高,越需要"护栏(guardrails)":权限限制、花钱限额、人在环审批、可观测、兜底。OKX 让 agent 自主交易真金白银,就是把自治度推到很高的一档——所以"安全与信任"才是那个岗位的工程核心。
④

Agentic 设计模式总览(后面逐个展开)

基础

让 Agent Loop 变聪明、变可靠,业界沉淀出几个经典设计模式。它们就是这个大块后面要逐个点亮的模块,先混个脸熟:

🧩

规划 Planning

先把大任务拆成一步步子任务再执行,而不是走一步看一步。

→ 模块②规划与推理
🪞

反思 Reflection

Agent检查/批判自己的输出,发现问题再改一版,像自我 review。

→ 模块②规划与推理
🔧

工具调用 Tool Use

调外部工具/API(搜索、数据库、代码执行…)——就是循环里的"行动"。

→ 模块③工具与函数调用
🧠

记忆 Memory

把过往对话/经验存下来再取回,让 Agent 不"金鱼记忆"。

→ 模块④记忆系统
👥

多智能体 Multi-Agent

多个专精 Agent 分工协作(规划者/执行者/审查者),搞定单个搞不定的复杂任务。

→ 模块⑥多智能体协作
🛡

护栏 Guardrails

给自主的 Agent 装安全边界:权限、限额、审批、防注入。

→ 模块⑨安全与对齐
📌 全局观:这些模式没有一个是"另起炉灶",全都是往第②课那个"想-做-看"循环里加零件——规划让"想"更有条理,反思让它自我纠错,工具是"做"的能力,记忆给它历史,多智能体是把一个循环变成多个协作的循环,护栏给它套上安全绳。抓住"循环 + 加零件"这条主线,整个 Agent 架构就不散了。
