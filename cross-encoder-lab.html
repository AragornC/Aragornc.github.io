第 1 步 · 输入的根本差别:分开喂 vs 拼一起喂

同一对 query/doc,两种模型"读"法不同。这一步决定了后面准不准。

Bi-Encoder:两段分开,各进各的

query 和 doc 各自送进模型,互不相见:
query →
doc →
各自压成一个向量,最后才比 cosine。

Cross-Encoder:拼成一条,一起进

XLM-R 拼法:<s> query </s></s> doc </s>。注意中间是两个 </s>(RoBERTa 系分隔两段的写法),全程一条序列。

第 2 步 · "一起读"买到了什么:词与词的对视(注意力)

拼一起后,query 的每个词都能直接"看" doc 的每个词。鼠标悬停一个 query 词,看它能看到的 doc 词整行亮起。
⚠️ 诚实说明:这张格子画的是注意力的"连接结构"——每个 query 词都能看到每个 doc 词(全连接,这是 cross-encoder 的本事)。但每个格子真实的权重数值是模型 12 层训练出来、藏在内部的,ONNX 导出版不吐出来,所以这里不显示真实数值,只显示"谁能看谁"。Bi-encoder 这张图是空的:它俩从不在一起,没有跨段对视。

第 3 步 · 出口:bi 吐"方向接近度",cross 吐"相不相关的判断"

回到你的问题:cross-encoder 不是新物种。它和嵌入模型同底座(都是预训练 Transformer 编码器),只是拼一起喂 + 顶上加打分头 + 用"相关/不相关"标签微调。所以你用的是一个专门的 reranker checkpoint(单独下载),但它的"血统"是复用的通用编码器。
